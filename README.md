# DriveEase – Car Rental System

A responsive car rental web application built using HTML, CSS, and JavaScript. DriveEase allows users to explore available cars, select rental dates, manage bookings, and view their booking history through a simple and user-friendly interface.

## Features

- **Car Listings:** Browse available rental cars.
- **Search and Filters:** Find cars based on available search and filtering options.
- **Booking System:** Select rental dates and book a car.
- **Date Validation:** Prevent overlapping bookings for the same car.
- **Booking History:** View previously saved bookings.
- **Cancel Booking:** Cancel a booking with confirmation.
- **Dark and Light Mode:** Switch between themes.
- **Responsive Design:** Supports desktop and mobile screens.
- **Local Storage:** Preserve bookings and theme preferences in the browser.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Explore the car listings and test the booking features.

## Data Storage

This project uses browser Local Storage to save booking details and theme preferences. The saved data belongs to the browser and device being used.

## Limitations

- This is a frontend demonstration project.
- It does not use a backend database.
- Online payments are not integrated.
- Bookings are stored locally and are not shared between users or devices.
